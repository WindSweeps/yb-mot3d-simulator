左右滑动查看完整能级图；键盘可聚焦图框后使用方向键。

在 ¹⁷⁴Yb 的 ¹S₀ → ¹P₁ 跃迁中，基态 J = 0，激发态 J′ = 1 分成 m′Y = −1、0、+1。图中固定量子轴 +Y，沿 Y 轴的激发态位移为 gJ μB m′Y BY；基态没有一阶 Zeeman 分裂。

红失谐光更接近向下移动的激发支路。BY > 0 时，沿 −Y 传播的 H 光驱动 ΔmY = −1；BY < 0 时，沿 +Y 传播的 H 光驱动 ΔmY = +1。两束相对各自 k 的 helicity 都是 +1。

标准主场为 B = b(−x/2, y, −z/2)，b > 0。V1/V2 使用 h = −1，与径向梯度相配；负主电流会反转梯度，光偏振保持原值。三维计算按当前位置的完整磁场方向分解偏振。

主电流正向：从 +Y 朝原点看，+Y 侧线圈逆时针、−Y 侧顺时针。偏置电流正向：从对应正轴朝原点看，两线圈均逆时针，产生该轴正向场。
