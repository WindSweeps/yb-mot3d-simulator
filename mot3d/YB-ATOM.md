# 镱多能级时序引擎

2026-11-26，接收 MOT 时序工作台加入镱多能级引擎。「纯蓝 MOT（399 nm）」使用 L2。「399 → 556 nm 顺序冷却」使用 L3，装载时关绿光，交接时打开绿光并关断蓝光。

| 引擎 | 轨迹计算 |
| --- | --- |
| 轻量散射模型 | ¹⁷⁴Yb，按各束光的失谐、偏振和总饱和参数计算散射 |
| 四能级或七能级稳态速率方程 | ¹⁷⁴Yb，分别求各磁子能级的饱和布居 |
| L1 镱磁子能级与光抽运 | 五种同位素，按超精细谱线和三维偏振求布居，宽线采用局部动量扩散 |
| L2 镱暗态与重泵浦 | 推进 ³P₀、³P₂、自发返回和有限时间重泵浦。可选连续存活权重计算亮态寿命 |
| L3 镱双波长与光移 | 在 L2 基础上为 556 nm 抽样离散散射事件，加入光偶极势、张量频移和 ³P₂ 穿过磁场零点时的非绝热转移 |

在「模拟引擎」中选择模型后点击「确认并重算」。同位素在该面板切换。重泵浦和光阱参数位于「通道时序」的「镱引擎时序参数」。选用某个重泵浦波长时，将它的**中心循环速率**设为正值，单位是每个暗态原子每秒的循环数。脉冲以距时序结束的时间定位，各重泵浦共用这个开关窗口。例如开启距结束 15 ms、持续 10 ms 时，结束前 5 ms 关闭。图上显示每路光的开关和速率。

## 布居、运动和收支

各束光在局部磁场上投影出 σ⁻、π、σ⁺ 分量。跃迁的受激速率包含相应偏振权重、Clebsch–Gordan 系数及 Doppler、Zeeman、AC Stark 失谐。消去各激发态后，对共享的基态磁子能级求速率矩阵的稳态并归一化。光力由净吸收动量决定，稀有级联按相应激发态布居抽样。³P₂ 的磁子能级由两次 E1 辐射和核自旋耦合权重决定。重泵浦循环速率折合了光功率、失谐、偏振及同位素分量的覆盖，空间强度按沿 X 的高斯束衰减。复用 ¹⁷⁴Yb 的有效级联分支作为其他同位素的初值。

运动采用 BAOAB 分裂。蓝光局部阻尼及协方差使用 Ornstein–Uhlenbeck 步，吸收涨落保留 XZ 交叉项，发射角用各向同性近似。L3 在漂移子步内按空碰撞上界抽样 556 nm。上界覆盖整个弹道区间的局部高斯强度和 Doppler、Zeeman、光移失谐，一次反冲后重建上界。时变通道按分裂步中点取值，脉冲开关和阶段边界是积分节点。³P₂ 磁势为 μB gF mF |B|。磁阱统计检查垂直磁力足以克服重力，并用相空间能量与计算边界的磁势下界判定束缚。

光偶极阱或一维晶格使用输入波长处的标量、张量极化率。光阱机械力取势能的负梯度，跃迁频移为激发态与基态的能量差除以 ℏ。线偏振方向在 YZ 平面可调，张量项采用电子态在超精细态中的平均。在 1 mG 尺度平滑磁零点附近的张量投影。现有界面需要填写所用波长的极化率，避免把静态极化率用于任意光频。定位 759 nm 附近的魔术条件需要同时给出光偏振和磁场方向。[Höhn 等式（1）、图 2](https://pure.mpg.de/rest/items/item_3627678_2/component/file_3686601/content) · [Khramov 等图 3、1064 nm 测量](https://arxiv.org/pdf/1309.7926#page=3)

入射样本在装载时间内分层布置，每个入射样本代表 ΦT/N 个原子。分裂发生在第一次同时有 ³P₀ 与 ³P₂ 概率的暗态跃迁。末态按概率分配权重，³P₂ 子轨迹继续使用独立的随机流。Kish 有效样本量先合并共同入射祖先的权重，防止把同一次入射重复计为独立样本。每个观测帧核对尚未入射、亮态、两类暗态、逃逸和各项损失的权重。导出文件的 `samplingDiagnostics` 给出阶段末收支，`recovered` 累计计算由重泵浦返回亮态的事件权重，重复返回可累计。启用「连续亮态存活权重」后，每步用实际散射率的累计危害更新权重。

Threefry2x32/20 以种子、入射轨迹编号、分支编号、时序阶段、积分步和事件类型寻址。修改功率、失谐或同一时窗内的重泵浦速率时复用相同的随机地址。修改时间网格会改变积分步的地址。多能级引擎由 CPU Worker 运行。窄线强饱和时，L3 的耗时随实际散射事件数增加。成像沿用带权散射及弱探针传播，模型的布居方程没有偏振梯度相干和多重散射项。装置的注入通量、重泵浦覆盖、梯度、成像效率及密度损失需要各自的实验标定。[Random123 参考实现](https://github.com/DEShawResearch/random123) · [费米镱亚 Doppler 实验，Kostylev 等](https://arxiv.org/pdf/1405.1161)

## 复算

```sh
node --test mot3d/*.test.mjs
```

- 六束共振光的强饱和算例验证 ¹P₁ 布居趋近 0.75。低饱和、正交三轴、无磁场与重力时，用 `ℏΓ/2kB` 得到 699.0 µK 的 Doppler 温度。在 1024 条轨迹上核对三轴动能，采用固定随机种子。
- 用独立的三态连续时间马尔可夫链核对四种可见重泵浦组合。取 Cho 等给定的有效速率与 1∶3∶5 分支，快速重泵浦极限的斜率依次为 6.55、6.2725、4.2325 和 0 s⁻¹。单开 649 nm 的 4.2325 来自 0.37 + 6.18 × 5/8。Cho 等正文给出 3.94 s⁻¹，其图 5 实测为 4.14 s⁻¹。有限速率时，部分原子仍等待返回，双光同时开启的亮态瞬时占比可以低于 1。[Cho 等第三节及图 5](https://arxiv.org/pdf/1111.6225#page=3)
- 50 G/cm 轴向梯度下，³P₂ 的 mⱼ = +2 轨迹在重力和四极磁势中演化 0.8 s。80、40、20 µs 三个步长的最大相对能量误差依次为 8.46 × 10⁻⁵、2.12 × 10⁻⁵、5.31 × 10⁻⁶。第一个步长对应 10,000 步。
- 556 nm 单光束扫过共振的首事件概率由 Lorentzian 时间积分独立得到。9,000 条轨迹与解析概率按二项抽样误差比较。另有张量势梯度、魔术极化率下的频移消去、两色交接、导出收支及同种子复算检查。
